# 移动版功能对齐 · 0.14.3-alpha.39

本版补齐桌面分享工作台、旧剧情选项的状态检查与退出清理，以及托管账户的中英文购买/余额显示。
普通对话、工具调用、记忆、梦境和自由剧情继续使用与桌面版一致的核心实现。

分享：聊天输入框或完成后的回复中选择“分享”（窄屏可能放在“更多”中）。选择对话、模板、标题、背景和贴纸；在“编辑工具”和“预览图片”之间切换。上下滑动工具页；预览中拖动贴纸；工具页可缩放、旋转、翻转、调整图层、删除，支持撤销/重做。支持 7 套模板、4 种比例、封面原话和长对话自动分页，导出 PNG 不请求 AI。

标题和封面摘录支持 Android 原生多行输入。点击其他按钮会先提交输入法的最新文字，再执行操作。手机预览使用 720 像素宽画布；导出保持 1440 像素宽。完整分享素材库已随包安装，因此安装包比以前明显增大。

图片保存在 MOD 的 `shares/日期时间-随机编号/`。点击“保存位置”可复制实际路径，再用文件管理器取图；本版不自动写入相册、不自动发送到其他应用。本地头像使用 `share-portraits/` 中的 PNG/JPG/JPEG（最大 12 MB、最长边 4096 像素），在文字页刷新并选择。该文件夹不存在时会自动创建。游戏 NPC 肖像仍直接读取游戏内容，包括美化替换。

移动版使用游戏字体，并尝试使用游戏附带的中文字体回退，不依赖桌面 Skia 原生库。导出排版功能一致，但字体外观与桌面版不同；游戏字体不支持的特殊字符/emoji 显示替代字符。横屏触屏、系统输入法及实际 PNG 输出仍需真机验证。

覆盖升级时保留 `config.json`、`data`（含 `memory-archive`）、`shares`、`share-portraits` 和游戏存档。无需部署后端。

# Android adaptation — 0.14.3-alpha.9

本目录独立维护手机版。手机界面在代码中固定启用，不需要先生成或修改 config.json；旧配置中的 MobileUiPreview 字段不再生效。本版使用右下角 AI 按钮，已删除 NPC 长按计时、命中检测、原版互动暂存与回放，以及长按专用 NPC／工具 Harmony 补丁。电脑版位于相邻的 vivantvalley_no_langgraph。

## 操作

0.14.3-alpha.8 修正关闭图标被重复乘以原版 4 倍贴图缩放的问题，聊天关闭入口直接使用原版像素叉号，最大 48×48 UI 像素。设置与关闭按钮统一在标题行，发送位于输入行。就地编辑器背景透明，内缩到游戏输入框边框内，编辑时只由系统绘制文字／光标，避免浅色大块覆盖和重复文字。键盘显示时聊天面板整体移入可见范围。尚需手机验证系统光标、字体与原版框体的实际贴合效果。

0.14.3-alpha.7 改为就地输入：点游戏字段直接唤起当前手机输入法，不再创建独立 AlertDialog 或黑色编辑窗口。系统 EditText 对齐当前字段，键盘挡住字段时将编辑区域移到可见范围；输入、退格、选中删除、粘贴和候选内容实时同步。密码仍遮掩显示。键盘完成／返回只收起输入，登录／发送和切换字段会先接收最后的编辑结果再执行，避免遗漏最后的输入或删除。底层保留原生输入连接来支持不同输入法，不模拟字母和退格键。真机重点验证密码单次／长按退格、删空后重输、中文候选、字段切换、横屏遮挡和返回键。

0.14.3-alpha.6 修复账户字段按旧 TextBox 宽度截断实际内容的问题。邮箱字符上限仍为 320，手机表单宽度不再影响保存的邮箱、密码、确认密码、验证码和模型名称。账户与 API 设置共用禁用宽度截断的字段工厂。输入过长时的显示省略不修改实际值。旧版本已经截断的邮箱或密码需重新输入。

安装包通过 SMAPI Launcher 的模组管理器导入。ZIP 内必须保留 `VivantValley/manifest.json` 和 `VivantValley/VivantValley.dll` 的目录层级，所有 ZIP 路径使用正斜杠 `/`。旧打包脚本在 Windows PowerShell 下可能写入反斜杠 `\`，导致安卓将路径当作散文件名；现已改为显式写入标准 ZIP 路径，并检查未转换的原始条目名。重新导入修正版不会自动清理此前产生的散文件，旧残留应单独移出 Mods 备份。首次验证先确认日志成功加载 Vivant Valley，再进入存档检查界面。

## 0.14.3-alpha.4 触摸与输入修复

触摸状态每帧读取一次并共用，菜单事件不再重复调用会推进状态的 TouchPanel.GetState。通过接触 ID 识别已被其他读取者推进到 Moved 的按下；已观察到的接触在前台消失时结束，在后台、多指、切换菜单或键盘开启时取消并等待手指全部松开。滑动后不会激活输入框。菜单不再通过 SMAPI 全面抑制模拟鼠标，改由菜单自身去重，并轮询补齐缺失的按住／松开回调。

输入框优先获取 SMAPI Launcher 的实际 SMAPIActivity.Instance，兼容 Game.Activity 属性或字段。原生编辑窗口显示并获取焦点后请求当前系统输入法。新增限频 Mobile input 日志，区分触摸采样、点击派发、请求键盘和编辑窗口已显示；不记录邮箱、密码、Key 或输入内容。离线测试覆盖丢失按下／松开事件、滚动、多指、指针替换、前后台及菜单切换；输入法弹出和键盘关闭后的连续操作仍需手机验收。

## 0.14.3-alpha.5 单击与邮箱输入

右下角按钮把先到的模拟鼠标按下和随后到达的单指触摸归为同一次接触，不再取消首次按下；释放只在统一轮询中完成，重复的鼠标释放不能结束原生接触。拖出、多指及失焦仍然取消。

原生编辑窗口打开期间，游戏按键通过 SMAPI 抑制，账户／API／聊天菜单不处理透传的按键，也不切换底层文本焦点。安卓聊天输入框不预先注册游戏键盘订阅者。邮箱使用 EmailAddress 和 NoSuggestions 输入类型；普通聊天仍保留中英文候选。编辑框在键盘显示前获取焦点，横屏禁用全屏提取编辑器，点击窗口外不关闭编辑框。未针对任何字母做过滤。

真机优先验证：首次单击右下角按钮即可打开；拖出取消；第一次打开邮箱后输入 `m`、`mm`、`m@example.com`，删除后重输、关闭后重开，以及密码和中文聊天的候选输入。首字符是否丢失需目标输入法验收。

- 未配置或未确认首次引导时显示“AI 设置”，无需靠近 NPC。
- 配置完成后显示“AI 聊天”。范围内一个 NPC 直接打开输入框；多个 NPC 显示可滚动姓名列表；无人时提示“请靠近村民”，并提供设置入口。距离继续使用 MaxTalkDistanceTiles。
- 选择 NPC 时重新检查位置、距离和资格。生成回复时只提示请求状态，不取消或重复请求。
- 事件、过场、小游戏、载入及其他菜单期间隐藏按钮。按下显示金色反馈；松手仍在按钮内才执行；拖出后再拖回也取消，多指或切后台取消。
- 默认右下角上方预留底部控制空间。在账户或 API 设置的“右下角聊天按钮”区域调整大小和横纵偏移，即时保存，返回游戏查看位置。
- 设置入口位于聊天输入框、NPC 列表及无目标页。已移除左侧旧 AI 按钮。
- 手机当前输入法负责中英文、候选、粘贴与选择。字段就地编辑并实时同步，“完成”收起键盘，游戏内“发送”才发请求。设置页不自动选择字段或弹键盘；点击字段再编辑。
- 保留触摸滚动、安全边距、响应式布局和会话内草稿。

## 首次设置

首次启用本版，进入存档并结束载入、起床后自动展示一次；标题画面不弹。MobileOnboardingVersion 与 Key／Token 独立，旧凭据也需要确认。

按钮可见性与点击、首次弹窗分别判断。玩家暂时不能移动、使用工具或焦点状态不正确，不会单独隐藏按钮；冻结控制或使用工具期间按钮禁用。自动弹窗在非床上、安全场景连续稳定 750 毫秒后展示，不依赖玩家 CanMove 字段。

设置成功成为当前菜单后才算已展示。事件或其他菜单期间等待；创建失败保留请求，至少间隔 5 秒重试，日志仅记录异常类型。检查在主要游戏业务更新之前执行。

“稍后设置 / 返回游戏”、关闭或返回键均可退出，本次游戏进程不反复弹出；未完成时下次启动仍展示。保存完整 API 配置、成功登录并保存，或确认已保存托管配置后才记录完成。保存失败不标记完成。确认旧配置不表示网络验证成功，断网不会删除原凭据。

## 配置

账户、API 和按钮位置均在游戏设置页操作，应用自动保存，无需手工编辑文件。下表仅供维护人员查看保存字段；界面启用没有配置开关。旧长按及左侧按钮字段不再使用。

| 字段 | 默认值 | 说明 |
|---|---:|---|
| MobileChatButtonScale | 1.0 | 按钮尺寸比例，限制 0.75～1.75 |
| MobileChatButtonOffsetX | 24 | 距右侧安全边界偏移；越大越靠左 |
| MobileChatButtonOffsetY | 160 | 距底部安全边界偏移；越大越靠上 |
| MobileOnboardingVersion | 0 | 引导完成版本；当前 1，由应用管理 |
| MobileUiScale | 1.0 | 菜单控件比例，限制 0.85～1.5 |
| MobileEdgePadding | 20 | 额外安全边距，限制 8～100；支持时叠加系统边距 |

## 验证范围与真机验收

离线回归覆盖按钮重复事件、拖出再返回、多指／指针取消、重置、零／单／多 NPC 路由、请求中防重复、引导旧凭据／跳过／重试／完成状态，以及横竖屏、安全边距、滚动与 Unicode。原有对话、剧情、提示词和本地化测试继续执行。

编译使用本地 PC 版 Stardew Valley 1.6／SMAPI 4 引用。构建及离线测试不能代替目标安卓加载器验收。真机优先验证：

1. 新安装或保留旧配置进入存档均展示设置，不自动弹键盘；跳过不重复，按钮可找回；保存后重启不再自动展示。
2. 无 NPC、单 NPC、多 NPC 的分支；目标离开后不可误选；回复期间不重复请求。
3. 点击、按住、拖出、多指、切后台和松手时，不走路、不送礼、不用工具、不误点新菜单。分别测试触摸移动和虚拟摇杆。
4. 按钮区域外的普通 NPC 点击、原版送礼、商店、工具与移动正常。
5. 中文候选、英文、粘贴、删除、返回键与键盘完成；设置初次展示无键盘遮挡。
6. 横竖屏、UI 缩放、刘海／导航栏、不同原版控制布局；尺寸／偏移保存后仍可见，所有设置可滚动到达。
7. 登录、连接测试、保存失败和断网重试；不将本地字段完整当作联网成功。

## 实现

ModEntry.Touch.cs 管理按钮及引导。MobileHudCaptureMenu 在游戏更新前接管按钮接触，直到松手所在游戏更新结束后再退出或打开目标菜单。仅抑制模组 HUD／菜单相关的模拟鼠标事件，不修改 NPC 或工具互动。

MobileChatPolicy.cs 提供可独立测试的按钮手势、路由与引导状态。MobileActionMenu 显示 NPC 列表。TouchMenu、各 .Mobile.cs 页面及 AndroidTextInput 保留触摸滚动和当前输入法能力。剧情规划、中英文提示词、模型请求与剧情结算沿用现有逻辑。

## 0.14.3-alpha.3 入口诊断

启动日志固定输出 `Mobile UI enabled unconditionally`，另行报告安卓原生接口识别结果；原生识别失败不再关闭 UI。进入存档后记录 `Mobile entry state`，说明按钮隐藏或引导等待原因，状态变化日志间隔至少 10 秒；首次实际绘制记录 `Mobile AI button drawn` 和按钮／视口尺寸，不记录凭据。

焦点兼容处理允许从未报告激活的宿主继续操作；观察到有效激活状态后，后台切换取消输入。不同加载器下的后台事件与触摸行为仍需真机验证。

本版回归特别覆盖无 UI 开关的新配置、入口可见／可点击／自动弹窗分离、工具／床上／冻结／后台状态和剧情菜单遮挡。安装后直接进入存档验证，无需创建 config.json。
